# Talking Santa & Friends website

A small static website for the app: home, support and privacy pages.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example `talkingsanta`) and upload everything in this folder.
2. In the repository, go to Settings › Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. After a minute your site is live at `https://YOUR-USERNAME.github.io/talkingsanta/`.

Use these links in App Store Connect:
- Support URL: `https://YOUR-USERNAME.github.io/talkingsanta/support.html`
- Privacy Policy URL: `https://YOUR-USERNAME.github.io/talkingsanta/privacy.html`
- Marketing URL (optional): `https://YOUR-USERNAME.github.io/talkingsanta/`
